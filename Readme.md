# Enchiridion — Personal Finance App

A minimal, fast personal finance dashboard built to track expenses, income, and monthly cash flow. Designed for individual use with a clean dark theme and client-side data persistence.

🔗 **Live App:** [enchiridion-finance.vercel.app](https://enchiridion-finance.vercel.app)

---

## Features

- **Dashboard:** Overview of total balance, monthly income, operating expenses, and net profit.
- **Charts:** Visual breakdown of monthly cash flow and expense categories using Recharts.
- **Date Filters:** Monthly and annual views with custom timezone-safe date parsing.
- **Access Control:** Simple password-protected entry screen.
- **Data Persistence:** Uses `localStorage` with custom events to keep UI state in sync.

---

## Tech Stack

- **React + TypeScript**
- **Vite**
- **Tailwind CSS**
- **Recharts** (data visualization)
- **Lucide React** (icons)
